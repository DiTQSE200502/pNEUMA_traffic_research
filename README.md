# pNEUMA_traffic_research
Traffic analysis and speed forecasting using pNEUMA data.

## Data source

The original pNEUMA dataset is available on
[Zenodo (DOI: 10.5281/zenodo.10491409)](https://doi.org/10.5281/zenodo.10491409).

### Required data coverage

To reproduce the study, download all available recording files
for all areas from `d1` to `d10` and all recording periods
on each of the following four dates:

- 24 October 2018 — `20181024`
- 29 October 2018 — `20181029`
- 30 October 2018 — `20181030`
- 1 November 2018 — `20181101`

Keep the original filenames so that the notebooks can identify
the date, area, and recording.

The study used 199 recordings. Before running Notebook 2,
check the input file inventory and manifest generated by
Notebook 1 against this coverage.
